# Pareto methodology

All finite task scores with a known positive total parameter count are retained from the September 17, 2026 MTEB API snapshots, including closed-weight models. Their exact source URLs, snapshot hashes and exclusions are in [pareto-data.json](pareto-data.json). The horizontal axis counts the whole stored model, including all three Vela modalities; reported peer counts can be rounded or outdated. No unknown size is imputed. Model-card and registry specifications can differ (for example Jina Text Nano); the registry coordinate is retained rather than silently mixing specifications from another date.

The frontier uses every displayed observation: a point is dominated if another is no larger and no lower scoring, with at least one strict improvement. Pairwise dominance and a separately implemented sorted sweep agree. All four plots include both Vela models. Labels are reading aids, not eligibility filters.

Reported and independently measured observations remain separate, even for the same model. F2's reported size has an explicit checkpoint-based correction in its report; its actual rerun uses the official task instruction, BF16 and an 8192-token limit. AST's old API point has 87M rounded parameters and no revision; it is not silently normalized. The new AST point counts all 86,594,063 parameters of the pinned checkpoint (86,187,264 execute as the encoder) and uses the official AST processor/raw pooler, FP32, batch eight, all 1,705 Vehicle rows and ten default clustering repetitions with seed 20260918. No training or task tuning is involved. The original NumPy/tensor interface failure and the narrow compatible wrapper are retained in its evidence.

Nano's English coordinate retains the actual evaluated artifact and applies through exact text identity. Nano audio coordinates retain their 96d evaluated identity. Nano now has 135,383,808 stored parameters after unused-branch removal; CPU/GPU bitwise synthetic parity and unchanged participating tensors support score applicability through [the public-inference bridge](inference-equivalence.json). No benchmark rerun or score improvement is implied. All raw identities, parameters, metrics and rich results remain in the linked reports. Within-task API protocol differences and unknown training overlap limit causal comparison. No official benchmark-wide or size-SOTA claim follows from these four task-level plots.
