# Ecosystem logo assets

These white display assets use the logo artwork supplied in the project's
Ecosystem presentation. White-stencil exports preserve the source marks' geometry
and internal negative spaces, with colored backgrounds removed where needed.

Each self-contained SVG embeds a losslessly compressed, cropped white-alpha PNG
export. No runtime filter, remote image, or font resource is required. These are
raster-backed SVGs, not newly drawn vector logos. The wordmark PNG contains the
same artwork as `vllm-sr-wordmark-white.svg`.

`atmosphere.webp` is the generated background plate. `ecosystem.webp` is a static
export of the homepage ecosystem section for the repository README. Keep its
logo order and copy synchronized with `EcosystemSection.tsx`.
