# Decision 2.0 visual direction

The public first-release card keeps the Decision family's own mosaic owl as
the recognizable subject. Give each size a new model-name banner, using the
clear 1.0 composition without copying its wordmark. The 2.0 banner and card
must work at a Hugging Face thumbnail size. The fox and chibi sticker files
are previous design studies; the research bundle's fox audit README is not a
product card and must not be uploaded. Confirm the final card and collection
visually before making a model public.

| Role | Color |
| --- | --- |
| Decision 2.0 / primary cobalt | `#315bff` |
| Open baseline / warm coral | `#f46b50` |
| Decision 1.0 / slate | `#738299` |
| Accent / golden yellow | `#f4b642` |
| Paper / warm cream | `#fff9ef` |
| Text / dark ink | `#172542` |

The palette is shared by rank and model-by-task matrix SVGs.
Use the mascot as a small visual anchor alongside the title, not over a data
plot. Every chart keeps a textual title, direct labels, a plain-language scope
caveat and alternative text; color alone never encodes rank. Use the owl
consistently on the first-release cards and collection.
