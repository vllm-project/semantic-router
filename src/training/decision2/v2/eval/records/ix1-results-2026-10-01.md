## 2. DEV2.0-27B runtime defect (for the 27B and runtime owners)

Two long ToolRet requests (32 questions each, ≈ 15–18K tokens) fail deterministically in the shipped 27B runtime:
one returns `invalid_model_output` (a non-finite or malformed head output) on both attempts; the other aborts the
process with a GPU memory access fault (no-retry page fault) on every attempt, on two different GPUs. A third such
request faulted once while four other 27B processes were loading and succeeded on retry. No package up to 9B shows
this. Both requests count as wrong in the Index, as the kit prescribes for errors. Suggested follow-up: reproduce
the two requests (run IDs in the private receipts) on the batched gated-delta path and check the 32-sequence
padded batch for an index overflow or a kernel bound.

## 4. Calibration study (fits on our CAL partition only)

Fits on `panels/gold/cal.jsonl` (700 rows: 320 Choice / 290 Noul / 90 Score), answered by each package's own runtime:
one temperature per type and a Noul temperature + bias, by NLL. Noul is markedly over-confident on CAL at every
size, so the fitted Noul temperatures are well above 1 and the bias is close to 0. The stored Index predictions
were rescored with both transforms (private), and the stored own-panel predictions were rescored after returning
them to T = 1:

- **Temperatures alone change no answer** on typed FINAL, public 231 or CSS15 (all Choice) at any size.
- **The Noul T + b changes 14–33 typed-FINAL Noul answers and 1–4 public-231 answers per size** (net between −5
  and +16 correct of 2,000 typed questions).
- **Recommendation for every size: keep T = 1; no calibration-only revision.** None could pass successor item 1
  (a significant paired v3 gain), and item 8 would need a C1 event.
- Open: the release's CAL698 Noul fit (file `19cc1a8c…`) disagrees with this CAL700 fit while the Choice
  temperature agrees exactly; refit on CAL698 when its logits are located.
