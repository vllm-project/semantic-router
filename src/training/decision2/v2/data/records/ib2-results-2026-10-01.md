  - Agreement with gold: R1 97.7%, R2 97.7%; R1–R2 raw 100%, κ 1.0 (one model family). No defect flags; low

- **Error pattern (counts only; ids stay on node A):** `ytspam` gold spam, both reviewers on-topic (3; one is a

- Limitation: AI adjudication, not human annotation.

## Deviations and incidents

- **Amendment 1** (before any audit): Glaive holds 11,193 distinct first requests in 78,011 conversations, so the
  slot rule left 4,751 tool-call candidates; the slots were removed and constructed `fc_rel` negatives added. Run
  `c1` is superseded and was never audited.
- **Amendment 2** (before any review sample): G4 removed five families on run `c2`; one redesign each for `fc_sel`,
  `fc_args` and `gsm` ran on `c3` with every audit repeated from the start; two redesigns failed and were dropped.
- **Stage R sampler:** the first `review` call failed before drawing anything (it passed an argument that only IB1's
  unmerged round-2 code has); fixed in `2591cafb3` (all surviving families have both labels, so the stratification
  is the one the prereg describes) and the sample was drawn with that commit.
- **Reviewers:** IB1 used one subagent per packet; IB2 used one subagent per reviewer (two packets each), R1 and R2 in
  parallel, both in the foreground (`run_in_background: false`), each in its own directory with only its packets.
- **TRAIN below target** (24,518 vs 40–120k): the shortcut gate removed five of eleven families and the exclusions
  removed most ContractNLI documents; not filled by relaxing any rule.

## How tracks could use IB2

Add `m6/ib2/ib2.train.jsonl` as one block against a matched-token control (alone or with IB1), screened with HT-DEV
v2, with items 1–8 in force; item 8 needs the custodian C1 recheck first. Leave out `hover` and `gsm2` to measure
transfer from the other families alone; leave out `argq` and `hover` to avoid ShareAlike text. Measure Index effects
privately on frozen packages; IB2 DEV is a diagnostic only.

**For a later round (coordinator):** function selection and argument choice need a construction whose distractors
are matched to the gold on frequency *and* form (the gate still found .47–.49 option-only accuracy after
frequency matching); knowledge MCQ needs a source whose options carry no key signal; phishing email needs a licensed
legitimate-email corpus.
