## Dropped in phase 1 (and why)

- **`smish`** (Mendeley SMS phishing, CC BY 4.0): failed G4 `state_removed` in run a1. With a constant input and
  balanced 250 / 250 rows, this is fold noise, but the rule binds. It is not rebuilt in phase 1.
- **`w2c_act`** (When2Call train, CC BY 4.0): failed G4 `hypothesis_only` (the tool list predicts the action). G0
  already removed most groups, because the tool schemas are shared with Index tool rows. Not retried.
- **No licence-clean source:**
  - RAGTruth itself has NC contexts;
  - no licensed legitimate-e-mail corpus exists for phishing e-mail;
  - ContractNLI: IB2's train was emptied by G0 / G2, CUAD is protected and LEDGAR's licence conflicts;
  - Home appliances: the Index rows come from the kit's own generator, so any construction risks imitating it;
  - the original VAST, FinEntity and HellaSwag data are unlicensed or NC.
- **Phase 2 candidates:** VAST-like 3-way stance, GSM8K-like maths, HellaSwag-like continuation, MMLU-Pro / GPQA-like
  multiple choice. Each needs a licence-clean source and a G4-robust construction (`ib4-state.md`).
