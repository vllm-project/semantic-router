# Data arms v1: preregistration (2026-09-28)

Signed before any v1 arm row is generated or selected. It fixes sources, filters,
admission rules and audit methods. Frozen results (hashes, counts, audit receipts,
HF revision) go to `arms-v1-2026-09-28.md`; they may not change these rules. A rule
change is a new version with its own preregistration. Consumers: the experiment
matrix `experiment-matrix-v1-2026-09-28.md`.

Base dataset: private HF dataset `llm-semantic-router/decision-2.0-training-data`
at revision `b81b78e5477ed712418efda4db26a631ebd2bd2d` (TRAIN 7,455
`61740be4…243755`, SELECT 700 `32a4352d…20f2a6`, CAL 700 `3e34f6cb…7f60a`,
builder/rights manifest `61aa8830…9ee8`). A copy with identical hashes was verified
on node A before this preregistration.

## 1. Admission rules (every arm)

1. **Rights.** Only sources whose dataset *and* underlying-text terms permit private
   redistribution and model training: CC0, CC BY, CC BY-SA, Apache-2.0, MIT, ODC-By,
   ODC-PDDL, CDLA-Permissive, OGL, public domain, or text generated by our own
   generators (project code, no third-party text). Non-commercial, no-derivatives,
   research-only, unclear or platform-restricted text is excluded from v1. Attribution and share-alike
   obligations are carried per source in the arm manifest. Restricted raw source
   archives stay under `/data/dev2/private` on the nodes; only admitted rows are
   uploaded.
2. **Source isolation.** No source used by an evaluation, selection or calibration
   panel: the 15 CSS transfer tasks and 3 CSS pilot tasks; Decision Bench v4 record
   sources (CFPB, CommitPackFT, CUAD, BFCL, ContractNLI, UNFAIR-ToS, FiNER-139,
   SWE-bench, NVD, AgentDojo, τ-bench, HAGRID, civil_comments, ESCI, ABO,
   EDGAR-CORPUS, SEC 8-K, CORD, Upworthy, Spider, WikiTableQuestions, DocLayNet, AMI,
   Material Symbols and the rest of its manifest); JevBench public items; JevArena
   typed generators. Programmatic families must be mechanism-disjoint from the typed
   DEV families (attribute_gate, rule_precedence, set_reconciliation,
   transition_table) and FINAL families (constraint_competition, exception_stack,
   evidence_join, resource_ledger). Exception carried from A0: 120 FLUTE TRAIN rows
   (disclosed; `A0s` removes them).
3. **Item-group isolation.** Every row carries `group_id` = its original item group
   (source document, premise, passage, dialogue or generated scenario). A group lives
   in exactly one of TRAIN, the arm's held-out slice (AHO), SELECT, CAL or any
   evaluation panel. Exact id / group / `input_sha256` intersections across these are
   blocking.
4. **Protected overlap scan** against inventory PI-v2 (§2), with four methods:
   exact normalized leaf; the prior short-leaf rule (≤ 800-char protected leaves,
   compact six-grams, Jaccard ≥ .72 or containment ≥ .90); the same rule on 400-char
   compact windows (stride 200) of protected leaves longer than 800 characters
   (closing the 9,444-long-leaf gap); and rare n-gram containment (word 13-grams;
   compact 30-grams sampled by hash mod 4; grams seen in ≥ 5 protected rows or ≥ 5
   candidate groups are boilerplate and cannot quarantine). Any non-boilerplate hit
   quarantines the whole candidate group. A semantic embedding scan on node B GPU7
   (chunked states, cosine nearest neighbours) is run for every arm when feasible:
   groups at cosine ≥ 0.93 are quarantined; a fixed-seed sample of 20 pairs in
   [0.85, 0.93) is reviewed and reported. Approximate scans do not certify semantic
   independence; they bound verbatim and near-verbatim reuse.
5. **Answer-shortcut audit.** Group-disjoint 5-fold logistic regression on hashed
   n-gram features, per task type (≥ 30 rows): state-removed (instructions +
   options), option-only, and hypothesis-only (only when the state has a
   hypothesis/claim/statement field). Each must be ≤ majority + 5 points, where
   majority is the position/class/grade prior under the same folds. A failing
   family or source is not admitted as built; a repair is a new version. Reported
   diagnostics (not gates): full-input bag-of-words, longest option, lexical
   overlap, position prior.
6. **Balance.** Choice gold positions within ±5 points of uniform per option-count
   bucket (deterministic rotation where the source allows); Noul true share within
   45–55%; A6 grades exactly balanced per level count and rows per level count within
   ±5%. Other arms report their distributions.
7. **Native budget.** Every TRAIN row ≤ 8,192 native tokens (official Qwen3.5
   tokenizer, repository `encode`). Rows above 1,024 native tokens under the Kai
   tokenizer are flagged T1a-ineligible, not removed.
8. **Verifiable oracles (programmatic arms).** Labels come from structured facts and
   are independently recomputed from the rendered text; any disagreement drops the
   row and is counted (expected 0). Counterfactual groups share byte-identical
   instructions and options and realize every gold exactly once.
9. **Freeze.** Content hash = SHA-256 of the canonical JSONL (rows sorted by id,
   canonical JSON per line). Manifest: rows/groups by task type, language, source,
   family; Score by level count and grade; Choice by option count and gold position;
   Noul balance; state-length quantiles; native tokens per tokenizer; license table;
   hashes of overlap and shortcut receipts; builder commit and tree hash. Built only
   on a node from an exact mirror of a pushed commit.
10. **Held-out slice.** Each new arm reserves 10% of its groups
    (`sha256(group_id) % 10 == 0`) as `AHO-X` (split `select`, diagnostic only; never
    used for checkpoint selection, which stays on SELECT700).

## 2. Protected inventory PI-v2

Built on node A from hash-verified input-only files; the inventory manifest hash is
recorded in the registry before any arm scan. Roles:

- The eight core roles of projection `26bbaf82…897e1` (typed DEV 1,600; CSS pilot
  1,430; typed FINAL gold-free 1,600; CSS15 gold-free 6,547; JevBench public 231;
  rights-clean TRAIN 7,455 / SELECT 700 / CAL 700).
- Decision Bench v4 text-readable prompts (1,041).
- Every other previously built development or candidate panel present on the nodes
  as gold-free prompts: JevArena multilingual dev v1/v2 and parallel dev v1,
  multilingual-hard r5/r6/r7 (and r7-r2), authored v3/v4 candidate dev/release
  panels, the zh decision bench v0.1 items (projected to inputs only), Score v3
  gold-free prompts and the Score English pilot gold-free panel. Answer-bearing
  fields are removed by a projection step before hashing; files that cannot be
  projected are listed as excluded.

For A0 itself the TRAIN/SELECT/CAL roles are excluded from the self-comparison, and
a separate within-A0 report lists cross-partition near pairs.

## 3. Arm specifications

| Arm | Content | Source and rule | Target size |
| --- | --- | --- | --- |
| A0 | Existing TRAIN as-is | Frozen bytes `61740be4…`; stats, tokens, PI-v2 scan (incl. long leaves) and shortcut audit are *reported*; A0 is not re-filtered so prior runs stay comparable | 7,455 rows |
| A0s | A0 minus FLUTE | Drop the 120 `css_flute_official_train` rows | 7,335 rows |
| A0p | Option-order augmentation of A0 Choice rows | Each Choice row with ≥ 3 options whose instructions contain no positional reference (first/second/last option, A/B/C, 第一/第二/最后) gets one copy with a fixed derangement seeded by `sha256("a0p-v1" + id)`; same `group_id`, id suffix `:p1`; Score and Noul rows untouched (level order is semantic) | ≤ 3,908 rows |
| A1 | Cross-domain original human labels | Sources chosen by the rights/isolation screen; amendment (sources, revisions, filters, projections) committed before build | ≥ 0.5 × A0 tokens if available |
| A2 | Verifiable rules and counterfactuals | Generator `v2.data.verifiable` arm `a2`, seed `decision2-a2-v1`; families calendar, counting, multihop, injection, ordering, units; Choice + Noul; en ≈ 70%, zh ≈ 30% | ≈ 6,000 rows |
| A3 | Real long-text evidence | Sources with built-in answerable/unanswerable or supported/unsupported contrast; amendment before build | token-matched to ρ |
| A4 | Hard negatives, paired | Generator arm `a4`, seed `decision2-a4-v1` (seed namespace disjoint from A2); A4h (near-miss distractors) and A4r (random distractors) share ids, states, gold text and gold positions | ≈ 2,000 rows each |
| A5 | Multilingual native tasks | Natively authored non-English sources; amendment before build | ≥ 0.25 × A0 tokens |
| A6 | Score at all levels | Generator arm `a6`, seed `decision2-a6-v1`; band rubric, checklist, interpolation, rank position, evidence status (L=3); L = 2..10 balanced in rows, grades exact per L; plus admitted human ordinal sources by amendment | ≈ 5,400 rows |
| RP-v1 | Replay prompt set | Whole-group stratified sample of A0 TRAIN (seed `decision2-rp-v1`): 640 Choice, 512 Noul, 384 Score rows, languages proportional; frozen in training-row form (gold, for R1) and gold-free native prompt form (for teacher runs) | 1,536 rows |
| R2 targets | Own-1.0 soft distributions on RP-v1 | Per tier (Kai, Lex, Eos, Sol, Nox, Lux) with the tier's native runner; teacher probability parity against the runner's own output is a preflight; stored as `teacher_probs` replay rows | per tier |

Generator seeds, family lists and target sizes above are fixed. If an arm cannot
reach its target without breaking a rule, it ships smaller with the shortfall
recorded; rules are not relaxed to fill volume.

## 4. What is uploaded

A new revision of the private dataset adds `v2/` only: per-arm `train.jsonl`,
`aho.jsonl` (where defined), `manifest.json`, public (aggregate) overlap and shortcut
receipts, the RP-v1 prompt files, and a registry README. Root TRAIN/SELECT/CAL files
are unchanged; A0 is referenced by hash, not re-uploaded. Private receipts with
matched protected ids stay on the nodes.
