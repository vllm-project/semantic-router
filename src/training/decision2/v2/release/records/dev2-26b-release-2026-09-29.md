**Name.** The brief sets final names by actual loaded parameter count. The packaged runtime loads the
Qwen3.8-27B text backbone (only `model.language_model.*` tensors: 25,624,600,064; the 0.46B vision
tower, 0.42B MTP head and 1.27B LM head of the 27.78B checkpoint are not instantiated), the rank-16
LoRA (116,727,808) and the decision head (5,263,872): **25,746,591,744**. The build derives the
count from safetensors headers and both example processes assert it after loading. 25.75B rounds
to **26B**, so the release name is **DEV2.0-26B** (`name_basis: loaded-parameters`, size tier
still 27B). The same rounding reproduces all four released names (0.597B → 0.6B, 0.753B → 0.8B,
1.884B → 2B, 4.208B → 4B). The default tier rule is unchanged for other sizes. Under the count rule
a ~7.9B 9B-tier model would be named DEV2.0-8B; that is the coordinator's call when it comes up.
