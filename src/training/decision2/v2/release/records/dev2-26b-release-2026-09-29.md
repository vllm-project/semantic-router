## 11. Incidents

- **Attempt 1 failed before any compute.** The node HF cache stores LFS blobs in a shared
  content-addressed store (`hf-cache/blobs/<xx>/<sha256>`), and the repo's `blobs/` entries are
  symlinks into it. The container mounted only the repo directory, so `resolve_base` saw no shard
  and failed closed. Fix `b2c7c9448` mounts the store read-only as well, and all 31 files resolve.
- **The first card-only attempt failed at build (no GPU).** `8730d9413` (0.6B track, per-level
  Score offsets) changed the shared `training/model/infer.py` after F1 was scored, and the builder
  vendors from its own tree. Its scored-source check refused the package.
  - Fix: `vendor_source` (`a60409303`) vendors from F1's scored source mirror `35fa052d2`.
  - Every later release of a model scored before `8730d9413` needs the same (e.g., DEV2.0-4B / 2B
    finalization or card-only revisions: set `vendor_source` to the scored run's mirror).
- A background waiter matched its own command line and was replaced by a PID-based one; the run
  was unaffected.
