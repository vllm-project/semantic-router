## 2. Pipeline: `name_basis: base`

- `layout.base_size_label` reads the size label from the base repository name (`Qwen/Qwen3.5-9B` → `9B`; exactly one
  `<n>B` token). `layout.release_name(loaded, "base", base_model)` gives `DEV2.0-<label>` only if that size and the
  loaded count share a size tier.
- `build.name_base_model`: the naming base is `name_base_model` or an adapter's pinned `base.repo_id`. The two must
  agree, and the base must appear in the declared lineage (origin, licence components or pinned base). The manifest
  records `name_basis` and `name_base_model`.
- The card adds `- **Name:** Named after its base model ([<base>](https://huggingface.co/<repo>)); it loads N
  parameters.` under Model details, where N is the exact loaded count. The Parameters line with the components stays.
- `hub ensure`, `upload`, `readback` and `collect` refuse a repository ID that the Hub resolves to a different
  repository. A superseded spec such as `dev2-8b-release.json` therefore cannot upload to, or re-create, a retired
  name.
- Tests: [`tests/test_name_basis_base.py`](../tests/test_name_basis_base.py) (8 tests). The release suite gives 77
  tests OK, 1 skipped. The README documents both changes.
- Banners: the tier banners `DEV2.0-9B-owl-banner.png` (`d318952d…`) and `DEV2.0-27B-owl-banner.png` (`d79ea73a…`)
  are used unchanged (the `--label 9B=8B` / `27B=26B` variants are no longer used).
