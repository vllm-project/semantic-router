## 2. Card

Banner (vLLM-SR logo, `#30A0FC` / `#FCB414`, Inter on white, "Decision 2.0" + codename + size, tagline,
decision-graph motif) → title → pitch → at-a-glance table → Highlights → Quickstart (pip line, one Python block with
AutoModel + `system_one` and a commented `pipeline("decision")` line) → Evaluation → License → Citation. Evaluation is
JevArena and the Jev Decision Index only, with four charts, each carrying the logo bottom-right:

- JevArena overall;
- JevArena by decision type plus human-labelled transfer;
- the Index Pareto;
- the Index by area against the 1.0 counterpart (Vega against Lux 2.0).

Losses stay in the charts. Highlights state only true claims: top JevArena of its size (only when true; "statistically
level" when the runner-up is level), the gain over 1.0 (the Index part only when positive), the median single-GPU
latency, and many questions in one pass. The Index footnote is the user's text verbatim.

The Pareto chart uses loaded parameter counts for Decision 2.0 and the board's served counts for the other entrants.
The 0.8B `NOTICE` that was removed was our own, not an upstream file. Records and other tracks that cite the former
IDs keep working through the redirects.

The Index values live only in the private Index file and on the private cards. The receipts here hold only hashes
(`index_sha256`, `card-assets.json` with input and file SHA-256s).
