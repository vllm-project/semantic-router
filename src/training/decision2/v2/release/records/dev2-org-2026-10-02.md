- `org.sh <tier> --gpu N|--cpu` runs these steps in order:

  2. It builds a fresh package, and `org_check.py compare` must pass: only README.md changes, and it equals the
     released README with `llm-semantic-router/` replaced by `vllm-sr/`. The manifest differs only in its Hub
     references, the README digests and `builder.source_commit`, and no package text names the former organization.
  3. `gate profile` must pass (the superseded release's items).
  4. Hub pre-check under the new ID: it resolves to itself at `main`, privately, and the former ID redirects to it.
     Then AutoConfig and AutoTokenizer with `trust_remote_code` load it from the Hub, in a fresh cache in the release
     image.

  6. `release.sh --upload --collect --already-collected` (card-only, no parity), with every Hub and remote-code check
     of round 4 under Transformers 5.17 and 5.18.
  7. After the upload, `org_check.py verify`: `main`, private, the redirect, exactly README.md and MODEL_MANIFEST.json
     changed, no former-org text in any text file. Then card HTTP, links, the read-only collection check and
     `gate evaluate`.
