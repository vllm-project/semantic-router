## Package decisions for F1

- **Soup rule (17:15):** P_dev(soup) 77.03 ≥ the seed mean 76.64 (76.14,
  77.14), so the soup is the artifact.
- **Soup exactness:** 496 projections, max relative |ΔW_soup − mean ΔW| =
  2.7e-7 (limit 1e-6); head within 6e-8 of the float64 mean;
  `verify_adapter_config` passes; model SHA-256 `b7fd44e3…6e781`.
- **Proxy screen:** P can only drop candidates ≥ 8 behind. F1's CAL, adoption
  and formal stages started before the M3-S soup existed. The seeds' spread
  (75.25–77.14) makes a drop impossible.
- **CAL698 (23:15 rule):** temperatures fitted at 32,768 with
  `calibrate_frozen.py` (adapter base, kernels required). They are REJECTED:

  | Development panel | Raw (T = 1) | With CAL698 |
  | --- | ---: | ---: |
  | typed-DEV Brier | .089 | .106 |
  | typed-DEV ECE | .049 | .096 |
  | CSS-pilot ECE | .063 | .120 |
  | CSS-pilot Brier | .504 | .454 |

  CSS-pilot Brier is the only metric that improves. The package ships T = 1:
  the kernel adapter gets the rejected fit's binding with every temperature
  1.0, which is exactly what a release package with calibration `null`
  produces.
