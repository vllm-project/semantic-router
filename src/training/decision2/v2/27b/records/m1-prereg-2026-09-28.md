## Amendment 2 (after A1 attempt 1, before any outcome): native faults

A1 attempt 1 passed every preflight, then its full run exited 139 at update 5
(0.065 GPU-hours) with the kernel signature already documented for this image
(`pt_autograd_0` fault at `0x100000001`, then a `libhsa-runtime64` fault): an
intermittent native backward fault, not an OOM, nonfinite loss or data error.
BEST368 completed the identical update order on the same image. No SELECT
checkpoint existed, so no outcome was observed.

Rule for A1 and A2: exit 139 is an interruption, not a result. Before the first
checkpoint, one fresh restart in a new run directory with the identical
command; after a checkpoint, exact resume from the latest complete checkpoint
through the trainer's contract-checked `--resume` (same arguments, data cursor,
optimizer and RNG state). At most two recoveries per arm and 3.5 cumulative
GPU-hours including interrupted attempts; any other failure, a third fault or
the cap ends the arm as HOLD. Every attempt keeps its receipt. Checkpoint
schedule, selection and readout are unchanged.

## Decision rule (fixed now)

`P_dev = 100·sqrt(T_dev·H_pilot)`, `T_dev` = typed DEV family-macro accuracy,
`H_pilot` = CSS-pilot median task macro-F1 (mean macro-F1 also reported).
`σ_seed` := |P_dev(A2) − P_dev(C0)| / √2.

A challenger displaces C0 only if `P_dev ≥ P_dev(C0) + max(2.0, 2·σ_seed)`, no
DEV type (Choice, Noul, Score) falls by more than 3.0 points, `H_pilot` falls by
at most .015, and invalid answers do not increase. The Milestone 1 formal slot
goes to that challenger, or else to C0 as the incumbent. The formal run is
post-key v3 (typed FINAL 1,600 + CSS15 6,547) and public231, through the eval
track's frozen runner when announced, otherwise the pinned v3 runner. Selection
never uses v3 or public231; a formal readout does not reselect candidates.
A challenger needs its own package and full DEV/CSS-pilot parity first.

GPU caps: V+A3 3.5, A1 3.0, A2 3.0, readouts 1.5, formal 1.5 (total ≤ 12.5).
A failed preflight, nonfinite loss, OOM or cap breach stops that arm; it is
recorded and not rerun.
