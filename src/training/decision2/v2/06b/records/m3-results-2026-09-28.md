# 0.6B encoder track, Milestone 3: results

**Decision: HOLD, no finalist, no formal run.** No arm cleared the preregistered bar
(both seeds: CSS pilot H ≥ .281, typed DEV Choice ≥ 186/800, Noul ≥ 186/400), so the
frozen same-panel runner was not used. Every run followed `m3-prereg-2026-09-28.md` and
the amendments M3a-2, M3b-2, M3b-3 and M3c, each frozen before the runs it governs.
Development readouts (SELECT, typed DEV, CSS pilot) are never release scores. No Hub
upload (no finalist).

## 1. Padding root cause (`m3-padding-root-cause-2026-09-28.md`)

No padding defect in any trainer family: padded ≡ one-row in FP32 for the causal
endpoint, bidirectional marker and Kai/Lex native paths (the last with dropout zeroed).
The Milestone 2 attribution of the stall to padded micro-batching is withdrawn; the
EuroBERT and bidirectional-Qwen runs are *invalid as architecture evidence* (an
optimization failure of that recipe), not implementation failures. The new CPU tests and
preflight gate caught one real latent bug (causal teacher mapping on partially covered
micro-batches), fixed before any Milestone 3 arm relied on it.

## 4. Findings

1. **The early collapse is a schedule effect.** With a 2e-5 backbone peak after 5%
   warmup (batch 16), fresh-head causal runs collapsed at the end of warmup in 4 of 10
   runs (Milestones 2–3: padded 3/4, one-row 1/6). With 1e-5 and 10% warmup,
   4/4 causal seeds trained (a2 and a2c), learned faster (SELECT 449–493 at update 85–100
   vs 239–310), and reached the track's best SELECT (572, 574). Padded micro-batches are
   now the default.
2. **Bidirectional official Qwen still does not learn** under any remedy tried (freeze,
   one-row, FP32, 5e-6, the (a2) schedule). The line is closed until an adaptation stage
   (for example masked next-token training) is designed; EuroBERT was not rerun.
3. **A6 breaks the constant-level Score collapse but misses the effect rule.** Without A6
   typed-DEV Score is one level (85/400) on both control seeds; with A6 it spans 2–3 levels
   on both seeds and rises by 1.8 / 9.5 points. The primary effect fails matrix v1.1's rule
   (seed-1 interval includes 0; seed 2 below 2σ_seed = 11 points), and seed 1 breaks the
   H retention floor (−2.3 points > 1.5). At T1a the A6 factor is therefore *not passed*;
   the program decision rests with the T1b (0.8B) testbed.
4. **Seed variance is the binding problem.** One recipe's two seeds differ by P +5.1
   [+2.8, +6.7], typed Choice by 11 points and typed Score by 8 (σ_seed(P) ≈ 3.6, beyond
   the eval track's ±1.3 panel noise and its |ΔP| < 4 tie band). Typed-DEV Noul is
   192/400 with identical per-item answers on all four (a2)/(a2c) checkpoints (paired Δ
   exactly 0), consistent with one constant answer.
5. **The Kai lineage with A6 + Lux1** raises typed DEV (T_dev .345 / .364 vs .266; Score
   208 / 175, three levels on s2) without better transfer (H .176 / .157 vs .175): the
   eval track's "T up, H down" pattern. Versus causal (a2) s2 it loses 7.5 P, all of it
   transfer.

## 5. Decisions taken and proposed next step

- Taken under the autonomy mandate: no formal run (rule); the (a2) schedule replaces
  2e-5 / 5% for every fresh-head 0.6B arm; padded micro-batches are the default; the
  bidirectional line is closed pending an adaptation stage; A6 recorded as *not passed* at
  T1a with its qualitative Score-level effect disclosed.
- Next (Milestone 4): run the (a2) recipe on mixture v2 with the canonical Lux teacher as
  soon as both are published (the trainer takes their hashes as they are), with three
  seeds and a matched template-S control, and pick finalists on the seed mean with the
  floors applied to every seed; attack the seed variance (larger logical batch with
  scaled learning rate, weight averaging over the last checkpoints) and the constant
  typed Noul answer before spending on more architecture arms.
