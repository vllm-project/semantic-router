## Rights and reliability

The [dataset README](https://github.com/gazelle93/decision-models-under-pressure/blob/21820dc8b455e37aebaf5a83122233b6e564c109/dataset/v3/README.md) licenses the **data** CC BY-SA 4.0 because of MTOP. Attribute all upstream datasets and preserve ShareAlike when distributing prompts that contain the item texts. CLINC is CC BY 3.0, GoEmotions Apache 2.0, DBpedia CC0; the financial tweet dataset's MIT grant is uploader-stated and underlying posts have uncertain rights. At this revision the repository has no root code license. Write our own small reader/compiler from the documented JSON schema instead of copying its harness.

The same manifest explicitly says `gates_passed=false`: the text-blind gold picker (G3) exceeds its 0.125 gate in six of ten domain/tier cells at K16, including DBpedia near 0.260 (chance 0.0625). Thus the level of absolute accuracy is contaminated by label-format shortcuts. RQ3 paired near/far and RQ2 order changes are more interpretable; report text-blind accuracy alongside model accuracy and stratify all figures by domain and `leaked`. CLINC has gold-string leakage on 25% of rows; MTOP on 6%. The items are public and could overlap training or pretraining.

## Single frozen compiler for every model

Build *one* immutable prompt file and private scoring file before any model run. For each selected source row, use `state = item.text` and a single question named `decision`: `{"type":"choice","instructions":"Which label applies here?","criteria":{label:label for label in ordered_options}}`. Set ordered options to the gold label plus the first `K-1` labels from the specified distractor pool, then shuffle with a documented deterministic seed formed from `(uid, pool, K, permutation)`. Store the source UID, domain, `leaked`, pool, K, permutation, option-set hash and prompt hash only in the scoring file; send only `state` and `questions` to the model. As in the existing unified benchmark, hash UTF-8 compact JSON of exactly `{"state":state,"questions":questions}` and require each prediction to echo this `source_input_sha256`. Gold is the source `gold` string. Preserve missing/invalid/truncated responses in the denominator. The same prompts, order, question wording and inference limits must be used for 1.0, 2.0 and open baselines; native adapters may translate this one typed request into the model's contract but may not add task-specific examples or edit the candidate descriptions.

RQ2's K64 is a separate capacity view; APUS's native runtime admits 2–16 candidates. No model should receive a quietly truncated candidate list.

Publish a row per model, revision and native adapter version with coverage, all-item accuracy, per-domain accuracy, near/far paired delta, order-flip fraction, identical-order repeat fraction, K-curve, wrong-answer confidence, Brier/NLL if the model returns a normalized distribution, latency under a separately matched deployment profile and source-overlap disclosure.
