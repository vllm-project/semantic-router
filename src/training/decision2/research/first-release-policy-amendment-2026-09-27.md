# Decision 2.0 first-release policy amendment

**Chronology:** this amendment was made after project-level access to the
JevArena v3 answer keys and after the official-Qwen 0.6B candidate's formal
score was read. It changes publication policy, not the v3 questions,
predictions, scoring formula or already sealed results. It must not be
described as a pre-key or blind preregistration.

The earlier [strict v3 release rules](jev-arena-v3-first-release-gates-2026-09-27.md)
required both axes to improve, a positive paired interval and no typed slice
decline greater than two points. The project owner has since directed that a
first release may make capability tradeoffs if the overall v3 improvement is
material, while disclosing every important regression. Those older rules
remain in the history; any candidate that fails them cannot be called a
"strict v3 gate pass." Do not retroactively relabel the evidence.

For each size's first public release, still require an eligible weight origin,
complete same-panel v3 and public JevBench predictions, a named near-size open
peer, unchanged scored model/CAL/prompt identity, exact downloaded-package
native-output parity, accurate source/rights attribution and a concise product
card. Report v3 aggregate point difference and paired interval, T/H, all
Choice/Noul/Score and human-task slices, invalid and over-budget responses,
and known regressions. A positive point estimate with an interval crossing
zero is a **measured but uncertain difference**, not a demonstrated general
win. Public JevBench is supporting evidence, never folded into v3 or called
the closed official benchmark. Later candidates developed after key access
need another independent confirmation before a broad superiority claim.

First-release visual assets contain same-panel rank and model-by-task figures
for JevArena plus the separately scoped JevBench rank. They contain no
parameter-efficiency Pareto figure. The optional Decision Index run follows
release and does not determine the first-release score.

The official-Qwen 0.6B BEST466 result is a private publication candidate,
not yet a model release. Its v3 point estimate is +2.5817 over Kai1 with a
paired 95% interval [-2.0317,+7.8464]; Choice and Score regress materially.
Any eventual release must state those observations and cannot claim a strict
v3 gate pass. Passing product-package verification cannot change its
statistical evidence.
