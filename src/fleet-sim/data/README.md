# Reference workload data

This directory is the repository-facing copy of the workload CDFs used by
Fleet Simulator examples and tests. The same data is included in the Python
package under [`fleet_sim/data/`](../fleet_sim/data/README.md), where the file
format, sources, and instructions for adding a custom CDF are documented.

Keep matching JSON files identical in both directories when updating a
packaged workload.
