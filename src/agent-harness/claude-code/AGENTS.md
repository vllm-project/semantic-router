# vSR Claude Code plugin

- This folder is a Claude Code plugin (`vsr`), listed in the root
  `.claude-plugin/marketplace.json` as `vsr@vllm-sr`. It is a client of
  `vllm-srun serve` and its public API; it never imports router or runtime
  code.
- `hooks/register.ts` hooks every event and hands it to one app module.
  `hooks/lib/describe.ts` is the one table of user-facing words, and
  `hooks/lib/classify.ts` the one way an app asks the runtime.
- Each `$.state` value is declared in `types/index.d.ts` under `vsr`.
- `hooks/lib/mark-art.ts` is generated by `tools/mark_art.py` from
  `assets/mark.png`; do not edit it by hand.
- `skills/setup/scripts/local.py` pins `vllm-srun` to a commit of this
  repository. Bump it only with a runtime the plugin was tested against.
- Before a change is done, run the four checks in `DEVELOPMENT.md`. CI runs
  the two Python suites; `claude plugin validate` and `claude plugin test`
  need the Claude Code CLI (2.1.319 or later).
